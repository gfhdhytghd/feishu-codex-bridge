# Markdown 图片读取权限

修改原因（用户原话）：**反正用lark-cli也能发**。

本地图片自动上传遵循项目对当前请求人的有效权限（包含管理员/访客分级）：

- `qa`（只读）：仅项目工作区及子目录。
- `write`（工作区读写）：仅项目工作区及子目录。
- `full`（完全权限）：允许本机任意位置的图片，仍需运行桥的系统用户可读取。

工作区限制按解析符号链接后的真实路径检查。相对路径以项目工作区为基准。
已有会话启动时也传递项目/会话工作目录，避免误用默认目录。
流式引用和最终回复采用相同权限解析；原有格式、大小和数量限制继续适用。

图片渲染、30 张上限、4 路上传并发及终态截止时间沿用上游实现；本分支补充解析符号链接后的权限边界检查。
